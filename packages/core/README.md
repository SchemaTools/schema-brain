# packages/core — логика без базы и сервера

Общая для сервиса, MCP-пакета и импорта. Каждое правило — по разделу `docs/spec.md`, с тестами: `npm test`.

| Модуль | Что | ТЗ |
|---|---|---|
| `enums.ts` | коды и русские названия; `fromRu` — код по коду или названию | 3.8 |
| `trust.ts` | n и b по людям (последняя отметка, без автора), показатель, «ложная» с двух отметок, показатель словами | 5.2, 5.3 |
| `queue.ts` | порядок очереди модерации | 5.6 |
| `versions.ts` | продукт и версия, пометка «проверить» и её снятие | 5.4 |
| `rules.ts` | допустимые связи, состояние при отправке, решения модератора | 3.2, 4, 5.5 |
| `tokens.ts` | токены `sbt_…`: выпуск, хэш, подсказка, заголовок | 2.1 |
| `search.ts` | разбор запроса (до трёх формулировок), латиница → кириллица, tsquery, слияние результатов | 6 |
| `format.ts` | короткий ответ агенту | 7 |
| `input.ts` | проверка записи от агента или формы, признаки личных данных | 3.1, 5.1 |

TypeScript без сборки: Node.js 22.18+ запускает `.ts` сам, импорты — с расширением `.ts`.

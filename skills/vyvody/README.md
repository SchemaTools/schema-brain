# Навык «Выводы» — версия 0.3

Навык для Claude и Codex (ChatGPT в бюро работает через Codex — решение 2026-10-15). По ходу рабочей сессии агент замечает, что стоит сохранить для коллег, предлагает до десяти коротких записей — вывод или открытый вопрос — и после «ок» сотрудника пишет md-файл в его папку выводов. Перед задачей и по ходу агент смотрит, что уже записано.

Два режима — навык выбирает сам:

- **сервис** — подключено расширение Schema Brain (инструменты `brain_*`, `tools/brain-mcp/`): поиск в общей базе по ходу задачи, отправка выводов и вопросов, в конце задачи — «сработало?» и отметки;
- **файлы** (шаг 0) — расширения нет или сервис недоступен: записи — md-файлы в папке выводов. Формат файла равен формату записи Schema Brain, модератор импортирует их без правки (`docs/spec.md`, раздел 9.1).

## Что делает

- Предлагает запись по событию: обошли ошибку, сотрудник поправил «у нас так принято», нашли ограничение версии ПО или нормы, повторили то же действие, не нашли ответа (тогда — открытый вопрос). В конце сессии — сводка.
- Не больше десяти записей за сессию; текст — одна-три фразы, до 300 знаков.
- Показывает запись целиком и отправляет (или пишет файл) только после явного «ок».
- В режиме «сервис» сравнивает новую запись с похожими из ответа: повтор → отметка существующей, противоречие → связь «противоречит».
- В конце задачи — один вопрос «сработало?» про применённые записи и отметки.
- Перед записью проверяет: длина, значения полей, нет имён, почты, путей, адресов, нет повтора уже записанного.
- Ищет в базе (или в папке выводов) перед задачей и когда упирается в незнакомое — несколькими формулировками.

## Как поставить

Для режима «сервис» поставьте ещё расширение Schema Brain — `tools/brain-mcp/README.md`; навык увидит инструменты `brain_*` сам. Без расширения навык работает с папкой выводов.

### Claude (приложение на компьютере)

1. Получите `vyvody.zip` у руководителя (или соберите: `npm run skill:pack` → `skills/vyvody/dist/vyvody.zip`).
2. «Настройки → Возможности» (Settings → Capabilities): включите «Навыки» (Skills), если выключены.
3. «Загрузить навык» (Upload skill) → `vyvody.zip`. Распаковывать не нужно.
4. Убедитесь, что навык «vyvody» включён.
5. Создайте папку выводов — например, «Выводы» в своей рабочей папке, — и дайте Claude доступ к рабочей папке.
6. Проверка: в новом чате — «куда ты записываешь выводы?». Claude спросит папку; ответьте и попросите: «запиши вывод: …».

Без доступа к файлам (обычный чат) Claude покажет готовый файл в конце — сохраните его в папку выводов сами.

### Claude Code

Распакуйте `vyvody.zip` в `~/.claude/skills/` (получится `~/.claude/skills/vyvody/SKILL.md`). Папку выводов назовите Claude при первой записи.

### Codex (и ChatGPT через Codex)

Распакуйте `vyvody.zip` в папку навыков Codex — по умолчанию `~/.codex/skills/` (получится `~/.codex/skills/vyvody/SKILL.md`) — и перезапустите Codex. Если ваша версия Codex навыков не видит, добавьте содержимое `SKILL.md` (без заголовка между `---`) в `AGENTS.md` своей рабочей папки, а `references/format.md` положите рядом и сошлитесь на него.

Новая версия навыка — удалите прежнюю и поставьте новую.

## Пилот шага 0

Пилот проводит руководитель: 3–5 дней, 5–6 человек (`docs/plan.md`).

1. Раздать `vyvody.zip`, у каждого — своя папка выводов (`docs/questions.md`, вопрос 6).
2. В конце — собрать папки (деперсонализированные копии, вне репозитория) и проверить формат:

   ```bash
   npm run skill:check -- <папка> [<папка> …]
   ```

   По каждому файлу — ✓ или ✕ с причиной, в конце — сколько годных выводов и вопросов.
3. Разобрать с Claude: что предлагалось к месту, что лишнее, что не замечено; правки формата и навыка — следующим PR, итоги — `docs/dev-notes/пилот-0.md`.

## Состав

- `vyvody/SKILL.md` — порядок работы: папка, подсматривание, когда предлагать, как формулировать, «ок», проверка.
- `vyvody/references/format.md` — поля, значения, примеры (вымышленные), «было → стало».
- `record.mjs` — разбор и проверка md-записи; сопоставляет русские значения с кодами сервиса. Его же возьмёт импорт сервиса.
- `check.mjs` — проверка папок выводов для пилота.
- `pack.mjs` — сборка zip: проверяет фронтматтер `SKILL.md` и все примеры из `format.md`.
- `record.test.mjs` — тесты: `npm test`.

Без зависимостей — нужен только Node.js 22 или новее.

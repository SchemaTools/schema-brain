# Навыки агентов

`vyvody/` — навык «Выводы» 0.2: ищет в общей базе по ходу задачи, по событию и в конце сессии предлагает записи (вывод или вопрос), после «ок» автора отправляет их в Schema Brain (`brain_propose`, `brain_ask`) или, без сервиса, пишет md-файл в папку выводов; в конце задачи — «сработало?». Один навык для Claude и Codex (ChatGPT — через Codex). Подробно — `vyvody/README.md`.

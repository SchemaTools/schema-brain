# Schema Brain

Общая память ИИ-агентов архитектурного бюро Schema: выводы из работы, открытые вопросы, типовые ошибки — с подтверждением делом, модерацией и графом связей. Агенты сотрудников (Claude, ChatGPT / Codex) подключаются через MCP; сервис работает в Docker на сервере бюро в локальной сети.

Статус: подготовка первой версии. Вводные для разработки — `CLAUDE.md`; решения — `docs/decisions.md`; план — `docs/plan.md`; ТЗ — `docs/spec.md`; стек — `docs/adr/001-стек-и-хранение.md`.

Репозиторий открытый: в нём нет данных бюро, имён, адресов и секретов — см. правила в `CLAUDE.md`. Перед каждым пушем — `bash scripts/check-private-data.sh`.

## Структура

Папки появляются по мере задач из `CLAUDE.md`.

| Папка | Что | Задача |
|---|---|---|
| `docs/` | решения, план, ТЗ, вопросы, ADR (`adr/`), заметки испытаний (`dev-notes/`) | 1 |
| `skills/vyvody/` | навык «Выводы» для Claude и ChatGPT / Codex | 2 |
| `tools/registry-scan/` | реестры проверок → кандидаты «типовая ошибка» | 3 |
| `packages/core/` | логика без базы и сервера: показатель доверия, очередь, разбор md-записи, перечисления — с тестами | 3–4 |
| `apps/server/` | API, работа с базой, команды импорта и выгрузки | 4 |
| `apps/web/` | веб: записи, очередь модерации, форма, граф | 4 |
| `tools/brain-mcp/` | MCP-пакет для агентов: ходит в API по токену; расширение для приложения Claude | 4 |
| `prisma/` | схема базы и миграции | 4 |
| `deploy/` | `docker-compose.yml`, `.env.example`, установка по SSH | 4 |
| `scripts/` | служебные скрипты, в том числе проверка на реальные данные | 1 |

Стек — как у Schema Teams: TypeScript (запускается без сборки, Node.js 22.18+), Fastify, Prisma, PostgreSQL 16 + pgvector, React + Vite; тесты — `node --test`.

## Разработка

```bash
npm install && npm run check
```

`check` — генерация клиента базы, проверка типов, тесты (с временной PostgreSQL), проверка на реальные данные. Установка на сервер — `deploy/README.md`.

Посмотреть вживую без Docker:

```bash
npm run web:build && npm run dev:local
```

Откроется http://127.0.0.1:3000 — временная база в `private/` с несколькими вымышленными записями; токен модератора для входа — в `private/dev-token.txt`. Начать с чистой базы — `npm run dev:local -- --reset`.

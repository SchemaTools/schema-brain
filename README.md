# Schema Brain

Общая память ИИ-агентов архитектурного бюро Schema: выводы из работы, открытые вопросы, типовые ошибки — с подтверждением делом, модерацией и графом связей. Агенты сотрудников (Claude, ChatGPT / Codex) подключаются через MCP; сервис работает в Docker на сервере бюро в локальной сети.

Статус: подготовка первой версии. Вводные для разработки — `CLAUDE.md`; решения — `docs/decisions.md`; план — `docs/plan.md`; модель данных — `docs/data-model.md`.

Репозиторий открытый: в нём нет данных бюро, имён, адресов и секретов — см. правила в `CLAUDE.md`.

# Разбор реестров проверок — кандидаты «типовая ошибка»

Читает xlsx-реестры замечаний единого формата бюро (шаблон v3 и ранние) и находит замечания, которые повторяются в **трёх и более разных альбомах** (решение 12). Результат — отчёт для модерации и, по выбранным номерам, записи шага 0 в формате навыка «Выводы» (`skills/vyvody/`).

Реестры и результаты — данные бюро: держать вне репозитория.

## Запуск

Нужен Node.js 22.18 или новее (TypeScript запускается без сборки) и один раз `npm install`.

```bash
node tools/registry-scan/src/cli.ts <папка с реестрами> --out <папка результата>
```

В папке результата:

- `кандидаты.md` — отчёт: кандидаты с образцом, другими формулировками, нормой, альбомами и черновиком записи; «почти кандидаты» (на один альбом меньше порога); предложения проверяющих с вкладки «Обратная связь» (тип «Кандидат в типовые находки»).
- `кандидаты.csv` — то же таблицей для Excel.

Записать выбранных кандидатов как записи шага 0:

```bash
node tools/registry-scan/src/cli.ts <папка с реестрами> --out <папка результата> --records 1,4,7
```

Записи появятся в `<папка результата>/записи/` — `ГГГГ-ММ-ДД — типовая ошибка К-1.md`; дальше — тот же импорт, что у записей навыка, и модерация.

Настройки: `--min 3` — в скольких разных альбомах; `--threshold 0.45` — порог сходства формулировок (выше — строже); `--date` — дата для записей.

## Как считает

1. **Какие реестры.** Все `*.xlsx` в папке и подпапках с вкладкой «Замечания»; временные файлы Excel `~$…` — мимо. Столбцы ищутся по названию («Замечание», «Норма», «Вид проверки», «Тип находки», «Статус», «Вердикт»), поэтому читаются и ранние реестры с другим порядком столбцов.
2. **Альбом** — шифр со вкладки «Об альбоме», иначе имя файла без «_реестр…».
3. **Не считаются:** вердикт «Ложное» (и «неверно», «нет»), «Игнорировать на проекте», статус «Снято», «Отклонено» проектировщиком без вердикта «Верное».
4. **Утверждённые типовые находки** (код ТН-xx в «Тип находки») считаются по коду.
5. **Остальные замечания** объединяются по сходству формулировок: слова приводятся к основе (падежи и числа), числа, марки и номера листов отбрасываются, «отсутствует», «не указан», «не приведён» → «нет», «не равен», «не совпадает», «не соответствует» → одно слово; сходство — косинус по весам слов (редкие слова весят больше) плюс прибавка за общий документ нормы.
6. **Кандидат** — группа, которая встретилась в `--min` и более **разных** альбомах. Пять одинаковых замечаний в одном альбоме — ошибка альбома, а не бюро.

Векторной модели нет (решение 2026-10-15): одно и то же, сказанное совсем другими словами, может остаться в разных группах. Такие группы объединяет Claude при разборе отчёта — для этого в отчёте есть образцы и «почти кандидаты».

Имена проверяющих и проектировщиков не читаются и в отчёт не попадают.

## Состав

- `src/registry.ts` — чтение реестра (ExcelJS).
- `src/text.ts` — приведение формулировок к сравнимому виду.
- `src/cluster.ts` — группы и кандидаты, черновик записи.
- `src/report.ts` — отчёт md, таблица csv, запись шага 0 (проверяется тем же разбором, что у навыка).
- `src/cli.ts` — командная строка.
- `test/` — тесты на вымышленных реестрах: `npm test`.

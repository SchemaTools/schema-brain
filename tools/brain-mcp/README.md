# MCP-пакет Schema Brain

Инструменты для агентов сотрудников — Claude (приложение и Claude Code) и Codex (ChatGPT в бюро работает через Codex). Пакет на компьютере сотрудника ходит в API сервиса по локальной сети; внешний адрес не нужен. Без зависимостей — нужен только Node.js 18 или новее (в приложении Claude он встроен).

Настройки: адрес сервиса и токен доступа `sbt_…` — их выдаёт модератор. Список инструментов зависит от прав токена: сотрудник не видит инструментов модератора.

## Инструменты

| Инструмент | Что | Право |
|---|---|---|
| `brain_search` | поиск выводов по ходу задачи; до трёх формулировок через «|» | чтение |
| `brain_get` | запись целиком по номеру | чтение |
| `brain_propose` | отправить вывод — только после «ок» сотрудника; в ответе — похожие записи | отправка |
| `brain_ask` | открытый вопрос; повтор вернёт номер прежнего | отправка |
| `brain_feedback` | «сработало / не сработало» | отметки |
| `brain_cores`, `brain_projects` | ядра и проекты | чтение |
| `brain_queue` | очередь модерации | модерация |
| `brain_list` | записи короткими строками — разбор с Claude | модерация |
| `brain_moderate` | принять, отклонить, объединить, заменить правило, вернуть, закрыть вопрос | модерация |
| `brain_link` | связи: противоречит, отвечает, выведен из | модерация |

## Подключение

### Приложение Claude

1. Получите `schema-brain-0.1.0.mcpb` у модератора (или соберите: `npm run mcp:pack`).
2. «Настройки → Расширения» (Settings → Extensions) → «Установить расширение» → выберите файл.
3. Впишите адрес Schema Brain и свой токен.
4. Проверка: в новом чате — «найди в Schema Brain что-нибудь про зоны обрезки».

### Claude Code

```bash
claude mcp add schema-brain --env SB_URL=<адрес> --env SB_TOKEN=<токен> -- node <папка>/tools/brain-mcp/server.mjs
```

### Codex

В `~/.codex/config.toml`:

```toml
[mcp_servers.schema-brain]
command = "node"
args = ["<папка>/tools/brain-mcp/server.mjs"]
env = { SB_URL = "<адрес>", SB_TOKEN = "<токен>" }
```

Токен — личный: не пересылайте его в общие чаты и не вписывайте в файлы проектов.

## Проверка

`npm test` — тесты против настоящего сервиса на временной базе: протокол, сценарий «отправка → модерация → поиск → отметка», повтор вопроса, права, ошибки связи и токена, запуск по stdio.

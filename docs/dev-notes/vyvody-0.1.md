# Навык «Выводы» 0.1 — заметки испытаний

## Проверено до пилота

- `npm test` — 17 тестов: разбор и проверка md-записи (годная запись, примеры из `format.md` и `docs/data-model.md`, CRLF и BOM, коды вместо русских значений, регистр, вопрос без вида, неизвестные значения, подтверждение автора, даты, длина 300 / 301, склейка строк, больше трёх фраз, личные данные, дубли и лишние поля, имя файла), фронтматтер `SKILL.md`, zip.
- `npm run skill:pack` — архив распаковывается штатным распаковщиком Windows, файлы совпадают с исходными.

## Не проверено — проверить на пилоте

- Загрузка `vyvody.zip` в приложение Claude и срабатывание навыка в обычной рабочей задаче (без слов «вывод» в просьбе).
- Codex: видит ли навык в `~/.codex/skills/`; если нет — вариант через `AGENTS.md`.
- Частота предложений: не мешает ли работе; хватает ли трёх за сессию.
- Как агент выбирает вид (факт / правило / гипотеза) и ядро; не выдаёт ли привычку сотрудника за правило бюро.
- Запись файла с длинным русским именем через доступ к папке в приложении Claude.

## Отклонения и сомнения

- Разбор записи написан на JavaScript без зависимостей, а не на TypeScript в `packages/core`: в репозитории ещё нет сборки, а навык и проверка нужны пилоту сейчас. В задаче 4 разбор переедет в `packages/core` вместе с тестами.
- Отметки «сработало / не сработало» на шаге 0 не пишутся: в формате md-записи их нет, отметка — отдельная сущность сервиса. Навык только говорит «в выводах есть …» и применяет.

## Открытые

1. **Показатель при нуле отметок.** `n/(n+b+1)` даёт 0 для свежей записи — она попадёт под порог 25 % как «ложная». Предложение: порог применять при `n + b ≥ 1`, до этого показывать «нет отметок». Принято как рабочий вариант до ответа.
2. **Счёт отметок по людям или по агентам.** У одного сотрудника может быть два агента (Claude и ChatGPT). Предложение: считать по людям — две отметки от агентов одного человека = одна.
3. **Пример реестра проверок** (xlsx, деперсонализированный) — нужен для `tools/registry-scan` (задача 3).
4. **Доступ к серверу** для задачи 5 — вне репозитория; когда основа готова.
5. **Лицензия открытого репозитория** — без файла лицензии код «все права защищены»; если нужна открытая лицензия, какая.
6. **Папка выводов для шага 0** у каждого сотрудника — одна общая синхронизируемая папка или у каждого своя; откуда сервис будет импортировать.

## Контур первой версии

```
Claude (навык «Выводы», подсматривание) ─┐
ChatGPT / Codex (тот же навык) ──────────┤→ MCP-сервер ─┐
                                                          ├→ API (записи, связи, токены, очередь) ─┬→ База (записи, связи, векторный поиск) ─→ датасет (JSONL)
Реестры проверок (xlsx) → импорт кандидатов ─────────────┘                                        ├→ Веб (список, граф, модерация, форма без агента)
                                                                                                  └→ Справка Schema Teams ← подтверждённые выводы
```

Всё — в Docker на сервере бюро, в локальной сети.
